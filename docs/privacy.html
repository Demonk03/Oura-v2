Политика конфиденциальности

Приложение «Oura v2». Обновлено 27 октября 2026.

Oura v2 — личный некоммерческий проект для отслеживания собственных показателей здоровья. Приложение не продаётся, не распространяется и используется ограниченным кругом людей, которые подключились к нему сами.

Какие данные обрабатываются

  • Показатели здоровья с носимого устройства: сон и его стадии, вариабельность сердечного ритма, пульс покоя, сатурация, частота дыхания, температурные отклонения, шаги, активность, тренировки
  • Идентификатор Telegram — чтобы связать аккаунт с данными и доставлять уведомления
  • Токены доступа к Google Health API и Oura API — чтобы забирать данные по расписанию

Приложение не собирает имя, адрес, платёжные данные и геолокацию.

Зачем

  • Показывать собственную статистику на персональном дашборде
  • Присылать уведомления при заметных отклонениях от личной нормы
  • Формировать еженедельную текстовую сводку

Данные не используются для рекламы, не продаются и не передаются третьим лицам для их собственных целей.

Где хранятся

В базе данных Supabase (PostgreSQL) с доступом только по серверному ключу. Веб-дашборд не обращается к базе напрямую: запросы идут через серверный слой, который проверяет подписанный токен и отдаёт пользователю только его собственные записи.

Кому передаются

  • OpenAI — обезличенные числовые показатели передаются для формирования текста уведомлений и еженедельной сводки. Идентификаторы аккаунтов не передаются
  • Telegram — доставка готовых сообщений пользователю
  • Supabase и Render — хранение и выполнение кода

Данные из Google API

Использование приложением информации, полученной из Google API, подчиняется Google API Services User Data Policy, включая требования Limited Use. Данные Google Health применяются исключительно для функций, описанных выше, видны только самому пользователю, не используются для рекламы и не передаются третьим лицам, кроме случаев, прямо необходимых для работы перечисленных функций.

Сколько хранятся и как удалить

Записи хранятся, пока аккаунт активен — история нужна, чтобы считать личную норму. Отключить сбор данных можно командой /stop в Telegram-боте. Полное удаление всех записей и токенов — по письму на контактный адрес ниже, в течение 30 дней.

Отозвать доступ приложения к данным Google можно самостоятельно на странице Сторонние приложения с доступом к аккаунту.

Безопасность

Токены и ключи хранятся в переменных окружения и в базе, в репозиторий не попадают. Передача данных — только по HTTPS. Проект личный, поэтому полных гарантий уровня коммерческого сервиса дать нельзя: подключайтесь, только если понимаете это.
